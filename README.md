# NOIR — Streetwear E-commerce Concept

A responsive dark-theme streetwear storefront built with HTML, CSS and vanilla JavaScript.

## Features
- Responsive layout for desktop, tablet and mobile
- Product category filters
- Add-to-bag interaction with live item count
- Mobile navigation menu
- Hero, collection, about and footer sections

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — filtering, cart counter and mobile menu

## Portfolio note
This is a reconstructed portfolio concept, not the original lost source code and not an operating store. Product names, prices and brand identity are sample content. Replace them with your own details before presenting it as a finished client project.
